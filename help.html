새 문서·폴더 만들기Create new files and folders

담당 폴더가 있는 분만 · Only for folders you're in charge of

새 문서: office.com → OneDrive → 내 파일 → 교회 폴더 → + 새로 만들기 → Word 문서 (또는 Excel)New document: office.com → OneDrive → My files → church folder → + New → Word document (or Excel).

새 폴더: 폴더 안에서 오른쪽 클릭 → 새로 만들기 → 폴더. 같은 분들과 자동 공유됩니다.New folder: right-click inside the folder → New → Folder. It's shared with the same people automatically.

PC에 Word가 없으면: 파일 오른쪽 클릭 → OneDrive → 온라인에서 보기로 브라우저에서 고치세요.No Word on your PC? Right-click the file → OneDrive → View online to edit in the browser.

+ 새로 만들기 · New 📁 폴더 · Folder 📘 Word 문서 📗 Excel 통합 문서
교회 파일을 바탕화면이나 문서 폴더로 옮기지 마세요. 다른 분들이 못 보게 됩니다. 필요하면 복사하세요.Don't move church files to your Desktop or Documents; others lose access. Copy instead.
📷

휴대폰에서 사진·스캔 올리기Upload photos and scans from your phone

담당 폴더에서만 · Only in folders you're in charge of

OneDrive 앱에서 폴더를 열고 + → 업로드 또는 사진 찍기In the OneDrive app open the folder → + → Upload or Take photo.

종이 문서: + → 스캔 → PDF로 저장Paper documents: + → Scan → saved as a PDF.

휴대폰에서 Word·Excel을 고치려면 Microsoft 365 Copilot 앱(예전 Office)도 설치하세요.To edit Word/Excel on your phone, also install the Microsoft 365 Copilot app (formerly Office).

되돌리기Undo and restore

이전 버전으로: 파일 오른쪽 클릭 → 버전 기록 → 원하는 버전의 ⋯ → 복원Older version: right-click the file → Version history → ⋯ next to the version → Restore.

실수로 지운 파일: 교회 폴더 파일은 팀 휴지통으로 갑니다. 93일 안에 IT 담당자에게 연락하시면 복원해 드립니다.Deleted by mistake: church files go to the team's recycle bin. Within 93 days, ask the church IT admin to restore them.

Mac에서 설정Set up on a Mac

App Store에서 OneDrive 설치 → 교회 이메일로 로그인 → 다음만 누르기 → Finder 왼쪽에 OneDrive - 방주선교교회가 생깁니다.Install OneDrive from the App Store → sign in with your church email → click Next → it appears in the Finder sidebar.

👤

개인 OneDrive와 함께 쓰기Using it alongside a personal OneDrive

작업 표시줄의 구름 아이콘 → ⚙ 설정 → 계정 → 계정 추가 → 교회 이메일. 개인 파일과 교회 파일이 따로 보입니다.Taskbar cloud icon → ⚙ Settings → Account → Add an account → church email. Personal and church files stay separate.
